# 图像生成与编辑技术

> 从图像与视频生成，到流模型与一步生成，再到编辑

这套书讲同一件事的不同层面：怎样让机器凭空造出图像与视频，怎样把采样压到一步，以及怎样在已有的图像或视频上按要求改。

三册各自独立，可以按顺序读，也可以挑着读。入门篇建立全景，进阶篇换一套速度场的语言讲生成，深入篇讲编辑。

## 怎么读

- 入门篇：第 1 章是全景，先读它建立地图；第 3 章补数学。
- 进阶篇：第 1 到第 3 章是地基，讲路径与速度场。
- 深入篇：第 1 章建立语言，第 2 到第 5 章按「改哪里」分类。
