# 深入篇

**图像生成与编辑技术 · 图像与视频编辑的原理**

这一册讲编辑：给定一张图或一段视频，怎么让模型改得对，又改得少。

## 讲什么

1. 编辑问题的形状
2. 在潜空间里改
3. 文本驱动：改写注意力
4. 反演的误差
5. 结构条件：告诉模型改哪里
6. 流模型的反演
7. 免反演：FlowEdit
8. ChordEdit：低能量传输
9. 视频编辑的特殊困难
10. 视频编辑的方法
11. 一步编辑的边界
12. 组合与工程实践

## 需要什么基础

知道扩散模型与流模型在做什么即可：噪声预测、采样、速度场。第 1 章会把用到的记号重述一遍。
