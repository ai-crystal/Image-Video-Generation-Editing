# 前言

这一册是一张全景图：把图像生成、视频生成与图像编辑的主要方法走一遍，说清每种方法解决什么问题、付出什么代价。

它不是实现手册。推导只到"能跟上思路"为止，遇到复杂的展开会说明这一步在做什么，然后给出结论。读完应该能做到两件事：看到一个陌生方法的介绍，知道它属于哪一类；被问到"为什么不用 X 方法"时，能说出它的限制在哪。

## 分成四部分

第一部分建立语言：生成问题的形状、图像与视频作为数据的基本事实、必要的数学。这几章不要跳，后面的记号都建立在这里。

第二部分讲图像生成：变分自编码器、对抗网络、扩散模型的训练与采样、条件引导、潜空间实现。

第三部分讲视频：为什么难、时空 U-Net、时间层、3D VAE 与潜空间视频扩散、长视频。视频是这一版新加的部分，逻辑从"多出来的时间维怎么处理"展开。

第四部分讲编辑与收尾：先换一个角度把生成写成一条路径，再讲一步生成，然后是图像编辑与视频编辑，最后给一张对照表。

## 关于公式

公式不多，但有几个必须看懂：证据下界、噪声预测的目标、条件引导的线性组合、流模型的速度场。这几处如果跳过，后面的内容会变成名词解释。

其余的公式，看懂每一项在做什么就够了，不必记住系数。书里尽量把"这个式子在说什么"写在公式旁边。

## 关于论文

正文提到的每一篇论文，都可以按方法名加 arXiv 编号检索到原文，例如 DDPM 对应 2006.11239。附录按主题列了清单。

原文的记号与本书不完全一致，尤其时间方向：扩散模型的论文大多让 t 从 0 走到 T 表示加噪，本册沿用这套记号，每章开头会重申一次。视频模型还多一个帧数 T，与扩散步数的记号容易混，正文里会用"帧数"与"步数"区分。
