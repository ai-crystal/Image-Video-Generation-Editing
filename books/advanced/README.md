# 进阶篇

**图像生成与编辑技术 · 流模型与一步生成**

这一册讲生成模型的另一套语言：不去一步步加噪去噪，而是直接学一个速度场，让它的积分把噪声搬到数据。图像与视频共用这一套语言。

## 讲什么

1. 从一条路径说起
2. 连续归一化流
3. 流匹配
4. 速度与分数
5. 整流流与重配对
6. 随机插值
7. 一步生成难在哪里
8. 一致性模型与蒸馏
9. 分布匹配与对抗蒸馏
10. MeanFlow：平均速度
11. 视频上的一步生成
12. 之后的路：改进、评测与工程

## 需要什么基础

知道扩散模型在做什么即可：前向加噪、噪声预测、采样沿轨迹往回走。第 1 章会把用到的部分重述一遍，并换成速度场的语言。
